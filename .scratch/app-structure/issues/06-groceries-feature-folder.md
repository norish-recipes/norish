# 06: Groceries into `features/groceries`

**What to build:** Web's groceries code moves into `apps/web/features/groceries/`: the screen, components (including `dnd`, `pantry` and `stores`) and web-only hooks. `app/(app)/groceries/` keeps only route files that seed and render the feature's screen. `MiniGroceries`, the panel other pages open, moves in too and is the one thing `features/groceries/index.ts` exports. See `.scratch/app-structure/spec.md`, "Features" and "Web layout".
