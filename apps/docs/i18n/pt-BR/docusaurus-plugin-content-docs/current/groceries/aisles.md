# Corredores

Uma Loja pode ter corredores para agrupar os itens da sua lista. Os corredores aparecem na ordem que você definir, inclusive quando estão vazios.

## Gerenciar corredores {#managing-aisles}

Abra **Gerenciar lojas** e edite uma Loja. Para adicionar um corredor, digite o nome dele abaixo do seletor de cor e pressione Enter. Edite um nome para renomear o corredor, arraste a alça para reordená-lo ou pressione **X** para removê-lo.

![O editor da loja, com os corredores da Loja abaixo do seletor de cor](/img/screenshots/groceries-aisles-editor.png)

## Organizar os itens {#sorting-groceries}

Arraste um item pela alça para movê-lo entre corredores. No celular, toque e segure a linha.

- Arraste-o para o topo da Loja para tirá-lo do corredor.
- Arraste-o para outra Loja para movê-lo para lá.
- Para escolher um corredor diretamente, abra o item e use o campo **Corredor**.

Itens sem corredor aparecem no topo da Loja.

![O cartão de uma Loja organizado por corredor, com as linhas sem corredor no topo](/img/screenshots/groceries-aisles-list.png)

## Como os corredores são lembrados {#how-aisles-are-remembered}

Os corredores são lembrados por Loja e por [ingrediente](/groceries/ingredients), então nomes diferentes para o mesmo ingrediente podem compartilhar um corredor. Por exemplo, colocar "melk" em Zuivel também coloca "milk" e "Melk (halfvol)" nesse corredor.

Renomear um corredor mantém os itens dele. Remover um corredor deixa os itens dele sem corredor. Cada Loja lembra os próprios corredores, e excluir uma Loja exclui as configurações de corredor dela.

Itens com o mesmo nome e a mesma unidade compartilham uma linha, então mover essa linha move todos eles.
