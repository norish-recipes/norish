# Receitas planejadas

Quando você planeja uma receita pelo calendário, pela seção **Hoje** ou pelo
botão **Adicionar ao calendário** de uma receita, o Norish abre o painel de
compras. Mude isso em
**Configurações => Usuário => Preferências => Depois de planejar uma receita**:

- **Nada**: só planeja a receita.
- **Abrir o painel de compras**: o padrão.
- **Adicionar os ingredientes às compras**: adiciona os ingredientes na hora,
  exceto o que está na sua [despensa](/groceries/pantry).

A configuração fica salva na sua conta, então vale para todos os dispositivos.
