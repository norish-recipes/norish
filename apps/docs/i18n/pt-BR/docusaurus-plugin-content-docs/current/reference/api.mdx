# Referência da API

Crie uma chave de API em **Configurações => Usuário => Chaves de API** e envie-a no cabeçalho `x-api-key` ou como `Authorization: Bearer <key>`. Substitua `https://norish.example.com` nos exemplos pelo endereço do seu próprio servidor.
