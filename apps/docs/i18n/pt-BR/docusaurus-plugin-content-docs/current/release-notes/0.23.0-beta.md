# v0.23.0-beta

## Resumo {#summary}

Esta versão é focada na experiência das compras. As lojas ganham corredores e
podem ser vinculadas a um mercado de verdade para buscar o preço dos produtos.

## Recursos {#features}

### Preços das compras {#grocery-pricing}

No painel de gerenciamento de lojas, agora você pode adicionar a URL de um mercado.
O Norish tenta detectar sozinho a URL de `query`, mas o jeito mais confiável
de fazer isso é buscar um produto no próprio site do mercado e copiar e
colar a URL. O Norish corrige o formato automaticamente.

- Um item de compra com preço mostra o seu **Preço de prateleira** na linha, com as
  palavras do próprio mercado para a embalagem, `€2.99 · 150 gram`, e a qual dos
  produtos do mercado esse preço se refere.
- O Norish só vincula sozinho um item de compra a um produto quando você não
  hesitaria, o que equivale, em linhas gerais, a correspondências exatas.
- Nem toda loja funciona automaticamente, por vários motivos; por exemplo, quando a
  coleta de dados do site é bloqueada. Nesses casos, é possível definir manualmente o preço, as
  quantidades etc.
- Os preços se atualizam sozinhos quando têm mais de doze horas e você está
  olhando a lista.
- Cada linha traz um **Custo da linha**: quantas embalagens inteiras a quantidade precisa
  pelo Preço de prateleira, `€5.98 · 2 × 500 gram`. Um número sem unidade é lido como
  número de embalagens, ou como unidades quando o mercado conta a embalagem em unidades; assim,
  "12 ovos" contra uma caixa com dez são duas caixas. O que o mercado vende a granel é
  cobrado pelo peso, então 700 g de bananas com preço por quilo custam sete décimos
  desse preço.
- No cabeçalho das lojas você vê o custo total dos itens **em aberto**.

[Preços](/groceries/prices).

### Corredores {#aisles}

As lojas agora podem ter **corredores**, gerenciados pelo painel da loja.

- Os itens de compra aparecem sob o seu corredor, com os itens sem corredor no topo.
- Arraste um item para um corredor, de volta ao topo para tirá-lo do corredor, ou para o corredor de outra Loja para movê-lo para lá.
- Você também pode escolher um **Corredor** no painel do item.
- Uma Loja lembra o corredor de cada **nome de item**, então o mesmo nome volta para lá na próxima vez que aparecer. Cada Loja tem a sua própria memória.

Os itens agrupados seguem as mesmas regras de corredor.

[Corredores](/groceries/aisles)

## Correções e melhorias {#fixes-and-improvements}

- Um ingrediente de etapa informado como quantidade é exibido com essa quantidade. "150 dos
  650 g" aparecia como 149.97 g ou 150.02 g abaixo da etapa porque a
  proporção guardada era arredondada; agora ela é guardada exatamente, então a quantidade que você digitou é
  a quantidade que os leitores veem. As quantidades informadas antes desta versão mantêm o arredondamento antigo
  até você informá-las de novo ([#550](https://github.com/norish-recipes/norish/issues/550)).
