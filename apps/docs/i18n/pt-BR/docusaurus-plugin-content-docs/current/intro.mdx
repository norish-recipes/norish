## O que é o Norish? {#what-is-norish}

O Norish é um gerenciador de receitas com planejamento de refeições e listas de
compras. As alterações são sincronizadas ao vivo: uma receita que alguém importa
aparece para você na mesma hora.

> **O nome** vem de Nora (nossa cachorra) + _dish_ (prato, em inglês). Por
> coincidência, também soa como _nourish_ ("nutrir").
