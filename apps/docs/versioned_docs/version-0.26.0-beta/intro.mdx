## What is Norish?

Norish is a recipe manager with meal planning and grocery lists. Changes sync
live, so a recipe someone imports shows up for you right away.

> **The name** comes from Nora (our dog) + dish. Coincidentally, it also sounds
> like "nourish".

## Core features

<FeatureGrid>
  <Feature className="sm:col-span-2" icon={<ArrowDownTrayIcon />} title="Import from any source">
    Import from websites, videos, images or plain text.
  </Feature>
  <Feature icon={<CalendarDaysIcon />} title="Plan and shop">
    Plan your week and make a grocery list.
  </Feature>
  <Feature icon={<ChartPieIcon />} title="Macro calculation">
    Nutrition worked out from the ingredients, metric and US conversion, and allergy warnings.
  </Feature>
  <Feature icon={<BoltIcon />} title="Synced in real time">
    Changes to recipes, groceries and meal plans appear for everyone.
  </Feature>
  <Feature icon={<DevicePhoneMobileIcon />} title="Mobile first">
    Made to use on your phone, even when offline.
  </Feature>
  <Feature icon={<ShieldCheckIcon />} title="SSO and password sign-in">
    Sign in with a password, OIDC, GitHub or Google.
  </Feature>
  <Feature icon={<LanguageIcon />} title="Multi-language">
    <Languages />
  </Feature>
</FeatureGrid>
