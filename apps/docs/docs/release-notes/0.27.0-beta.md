# v0.27.0-beta

## Summary

## Features

### Add your own Categories

Recipes are no longer limited to Breakfast, Lunch, Dinner and Snack. Type a new
Category, like Drinks or Desserts, in **Add a category** on the recipe form.
Your household can then pick it and filter by it. Other households don't see
it ([#442](https://github.com/norish-recipes/norish/issues/442)).

- Auto-categorization and AI imports pick from your household's Categories.
- Imports from other apps keep a category only when it matches one of yours.
  Any other becomes a tag.
- A Recipe Archive keeps its Categories. Importing one adds the ones you don't
  have yet.

See [Creating and editing recipes](/recipes/creating-and-editing#categories).

### iPhone sign-in

The iPhone app has new sign-in screens. Enter your server address, sign in with
an available method or create an Account when sign-ups are open. Signed-out
screens follow your device language, using a language enabled by your server
once connected. The app tells you when the server needs an update.

See [Mobile app](/mobile).

### Recipes on iPhone

Browse and filter your library, plan meals, manage cookbooks and add ingredients
to groceries from the Recipes tab. Import recipes from a link, text or photos,
or share them to Norish from another app. Your offline changes are sent when
you reconnect.

See [Mobile app](/mobile).

## Fixes and Improvements

- The Library's filter indicator now appears when only the favourites filter is on.
- When a favourites or minimum-rating filter finds no recipes, the Library and cookbooks show a no-results message.
- When an imported page contains no recipe, the failure message now says so.
- Cooking timer completion notifications now appear in your language.
- Each Settings tab has its own address: `/settings/account`, `/settings/household`, `/settings/caldav`, `/settings/ingredients` and `/settings/admin`. The User tab is now called Account.
- The CalDAV setup form puts meal times under **Advanced settings**, like the edit form, and prevents saving invalid times. The connection badge shows the latest check. Switching sync off and on keeps the selected calendar and trusted certificate, and the stored password is read only when the edit form opens.
- Removing an Avatar no longer restores an old picture. Transferring household admin now shows success only when the transfer succeeds. Failed Account and admin changes now show an error.
- Signing out or deleting an Account clears its offline copy even if clearing queued changes fails.
- The menu and confirmation button now say **Sign out**. If you try to sign out while offline, Norish says: "You're offline. Sign out when you're back online."
- When your session expires, Norish clears the device's offline data before the sign-in page. Queued changes are kept and sent when you sign in again with the same account.
- The CalDAV sync status and Ingredients list no longer flash an empty state while loading. CalDAV save, delete and sync messages and sync status rows are translated.

- On the calendar, moving, renaming or deleting a planned item now sticks after another item was moved out of or deleted from the same slot, such as Dinner.
- On the calendar, two quick changes to the same planned item are both saved, including changing a note's title and day or dragging a plan twice.
- Clicking beside text no longer leaves a blinking cursor behind. Only fields you can type in show one.
- The server accepts sign-in from the Norish iOS app again. No setting needs to change.
- `/api/v1/health/ready` now reports the server's version.
- On a server under a base path, the startup log now shows the HTTP and WebSocket addresses with that path.
- Checking off or adding a grocery does less work now, so the list feels quicker on a phone.
- Removing the saved API key under **Settings => Admin => AI & processing => Image generation** now enables **Save**.
- Each feature's code now has the same layout on web and mobile, and logic both apps need is written once, so Norish is easier to maintain and build on. Nothing changes for users.

## Upgrade notes

### Edited AI prompts and Categories

If you edited the **Auto-categorization**, **Recipe extraction** or **Image
extraction** prompt under
**Settings => Admin => AI & processing => Prompts**, your version still
names only Breakfast, Lunch, Dinner and Snack, so AI never picks a household's
own Categories. Copy your changes, press **Reset** to restore the defaults, and
apply your changes again. **Reset** restores every prompt.
