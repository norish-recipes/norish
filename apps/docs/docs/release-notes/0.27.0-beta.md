# v0.27.0-beta

## Summary

This release is mainly focused on architectural changes, the code has been reworked into feature folder. 

Apart from the architectural changes the mobile app got a lot of love and is almost ready for testflight (iOS only for now sorry Android), also focused on iPhone's, iPad and Foldable devices will come after. 

User facing changes are limited to: custom categories, import improvements, more nutritional data, bug fixes and memory usage improvements.

## Features

### Add your own Categories

Recipes are no longer limited to Breakfast, Lunch, Dinner and Snack. Type a new
Category, like Drinks or Desserts, in **Add a category** on the recipe create/edit form.
it ([#442](https://github.com/norish-recipes/norish/issues/442)).

- Auto-categorization and AI imports pick from your household's Categories.
- Imports from other apps keep a category only when it matches one of yours.
  Any other becomes a tag.
- A Recipe Archive keeps its Categories. Importing one adds the ones you don't
  have yet.

See [Creating and editing recipes](/recipes/creating-and-editing#categories).

### Notes on URL imports

URL imports now bring along the notes from a WP Recipe Maker or Tasty Recipes
recipe card, which used to be left behind. A page with several recipe cards
imports no notes. See [Importing recipes](/recipes/importing#from-a-link). Thanks to [@truffshuff](https://github.com/truffshuff) ([#729](https://github.com/norish-recipes/norish/pull/729)).

### More nutrition information

Recipe pages show fiber, sugars, sodium and saturated fat when available. The API returns these and other nutrients, along with nutrition per serving. See [Correct nutrition](../groceries/ingredients.md#correct-nutrition). Thanks to [@zelphir](https://github.com/zelphir) ([#677](https://github.com/norish-recipes/norish/pull/677), [#678](https://github.com/norish-recipes/norish/pull/678)).

### Code restructuring

The codebase was restructured so features share one layout across web and
mobile, and logic both apps need lives in one place. Nothing changes for users.

## Fixes and Improvements

- URL imports handle pages that load recipes with JavaScript or show them alongside reviews and related posts. With AI enabled, Norish can read ingredients and steps from the page when its recipe data is incomplete. Thanks to [@truffshuff](https://github.com/truffshuff) ([#725](https://github.com/norish-recipes/norish/pull/725), [#726](https://github.com/norish-recipes/norish/pull/726)).
- Paprika imports keep recipes separate when they share a source name such as "My collection". Thanks to [@truffshuff](https://github.com/truffshuff) ([#731](https://github.com/norish-recipes/norish/pull/731)).
- Pantry and ingredient searches match parts of words in any order, so "olive ex" finds "Extra virgin olive oil".
- Recurring groceries understand phrases such as "every other Friday".
- Metric ingredient amounts use rounded decimals, and fractions use common kitchen fractions.
- Running timers appear first, and timers match between the recipe page and cooking mode.
- The Library shows when the favourites filter is on and tells you when no recipes match your filters.
- Calendar edits save when you change a note and move it at the same time.
- The User settings tab is now **Account**.
- CalDAV keeps your selected calendar when you pause and resume sync, and checks meal times before saving.
- **Enrich All** runs in the background. You can follow its progress in **Job queues**.
- Arabic now uses a right-to-left layout. Thanks to [@hatemhamad](https://github.com/hatemhamad) ([#712](https://github.com/norish-recipes/norish/pull/712)).
- Norish uses less memory while idle. 
- The arm64 Docker download is about 25% smaller.

## Upgrade notes

### Edited AI prompts and Categories

If you edited the **Auto-categorization**, **Recipe extraction** or **Image
extraction** prompt under
**Settings => Admin => AI & processing => Prompts**, your version still
names only Breakfast, Lunch, Dinner and Snack, so AI never picks a household's
own Categories. Copy your changes, press **Reset** to restore the defaults, and
apply your changes again. **Reset** restores every prompt.

### API key rate limit

Set `API_KEY_RATE_LIMIT_WINDOW` and `API_KEY_RATE_LIMIT_MAX` to change the per-key limit. The default remains 500 requests per hour. See [Auth rate limiting](/configuration/server-runtime#auth-rate-limiting).

### Obscura 0.2.7

The Obscura browser moves to `norishapp/obscura:0.2.7-norish.1` (was
`0.2.5-norish.1`). It stops a page's chat widget from replacing the recipe while
it renders. The tag is pinned, so `docker compose pull` does not pick it up on
its own: change the `image:` line of the `obscura` service in your compose file
to `norishapp/obscura:0.2.7-norish.1`, then run `docker compose pull` and
`docker compose up -d`. Nothing else in the service changes. Thanks to [@truffshuff](https://github.com/truffshuff) ([#725](https://github.com/norish-recipes/norish/pull/725)).
