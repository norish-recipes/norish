# v0.26.0-beta

## Summary

## Features

## Fixes and Improvements

- The Edit button on the CalDAV settings card opens the editor again.
- Deleting a store can remove its grocery items again: the "Delete items" choice could not be selected.
- Notes in the planner can be moved to another day again: the note editor shows its date field.
- The Open link button in the recipe share panel opens the shared page again.
- Filter chips, timer chips and the library type switch work with the keyboard and screen readers.
- Norish no longer hangs at startup when an import was waiting in the queue.
- Norish has a new app icon and favicon, and an installed app shows it again on every phone. On iOS, remove Norish from the home screen and add it again to get the new icon.
- Installing Norish from the browser shows screenshots of the app.
- The calendar opens on today again, instead of sometimes weeks in the past.
- Scrolling the calendar while offline no longer hides the plans it already shows.
- A setting changed while an earlier change was still saving no longer flips back for a moment.
- Stores keep a fixed order in the store manager, and a Store dragged past several others no longer snaps back to an earlier place.
- A recipe enrichment that finished while its page was opening no longer shows as in progress.
- Pasted ingredient lists keep their amounts when the lines start with a bullet or a dash.
- Perplexity now uses Perplexity's Agent API; the Sonar API Norish used was retired on September 27.
- The recipe parser runs on Python 3.15, with its dependencies updated, security fixes included.
- Dependencies are updated to their latest stable releases.
- The unused image optimization endpoint (`/_next/image`) is no longer served.
- A deleted account is signed out everywhere at once, not on its next request.
- Sign-in rate limits hold when many requests arrive at the same moment.
- A new user signing in with SSO while registration is closed sees the sign-in error page instead of a raw error.
- Behind more than one reverse proxy, each visitor gets their own sign-in rate limit once `TRUSTED_PROXIES` lists the proxies.

## Upgrade notes

- **Node.js 26.** Norish now runs on Node.js 26. The Docker image already includes it. If you run Norish from source, upgrade to Node.js 26 before updating.
- **Back up Redis first if you might roll back.** The background job queue moves to a new major version with no way back. If you might return to an earlier Norish, back up Redis before updating.
- **Perplexity models.** Perplexity's models are now its Agent API presets: Fast, Low, Medium, High and Extra high. A Sonar model you picked earlier is moved to its preset when Norish first starts after the upgrade: Sonar to Fast, Sonar Pro to Low, Sonar Reasoning and Sonar Reasoning Pro to Medium, and Sonar Deep Research to High. Pick a preset in the AI settings to choose another.
- **OIDC callback URL.** The OIDC callback moves to `/api/auth/callback/oidc`. In your identity provider, replace the redirect URI `https://<your Norish>/api/auth/oauth2/callback/oidc` with `https://<your Norish>/api/auth/callback/oidc`; until you do, OIDC sign-in fails.
- **OIDC ID tokens are verified.** Norish checks each ID token against your identity provider's published signing keys. A provider that signs ID tokens with HS256 no longer works; give it an RS or ES signing key. Signing out of Norish still leaves you signed in at your identity provider.
- **Signing in no longer links accounts.** Signing in with a second provider whose email matches your account is refused with "This email is already in use." Link the provider from Settings instead.
- **New setting `TRUSTED_PROXIES`.** If Norish sits behind more than one reverse proxy, for example Cloudflare in front of Nginx Proxy Manager, list the proxies' IPs or CIDR ranges in `TRUSTED_PROXIES`. Without it, everyone shares one rate limit for signing in and session checks. See [Server & runtime](../configuration/server-runtime.md#networking--origins).
