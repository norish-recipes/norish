# v0.24.0-beta

## Summary

Under the hood, the realtime layer that keeps every household member's screen
in step is rebuilt: one connection to Redis per server, events that were missed
while a browser was disconnected arrive on reconnect, and a restart with
connected browsers completes in seconds. Image generation can now draw through
a local Ollama server.

## Fixes and Improvements

- **Missed events arrive after a reconnect.** A browser that loses its
  connection for a moment, a laptop lid closed, a phone locked, now receives
  what happened in the meantime, in order, before live events resume. Only a
  gap too large to replay falls back to a full refetch.
- **A server restart with connected browsers completes in seconds** rather
  than waiting out a thirty-second shutdown timeout. Browsers reconnect on
  their own, with a short random delay so a household's devices do not all
  reconnect at once.
- **The number of Redis connections the server holds no longer grows with the
  number of open browser tabs.** One subscriber connection serves every
  household member.
- **Ollama can draw.** Image generation gains Ollama as an Image Provider, for
  an Ollama server running one of its image models such as `x/z-image-turbo`.
  It takes an endpoint and no key, and borrows the endpoint from your AI
  configuration when that is Ollama too, so a fully local setup can now
  generate pictures without a second vendor. See
  [AI provider](../configuration/ai-provider.md#image-generation).

## Upgrade notes

- **WebSocket connections now check their origin.** An upgrade request whose
  `Origin` is not your instance's own is refused with `403`. If Norish is
  reached through a reverse proxy that rewrites `Origin`, or from more than
  one public address, list every public origin in `TRUSTED_ORIGINS` (see
  [Server runtime](../configuration/server-runtime.md)). A proxy that passes
  `Origin` through unchanged needs nothing.
- **The mobile app is parked and unsupported on this release.** It is not
  maintained against the rebuilt realtime layer and is expected to break until
  its rewrite ships. The web app is the supported client.
