# v0.25.0-beta

## Summary

This release introduces a major overhaul of ingredient management, using an ingredient catalogue.

This enables smarter pantry matching, automatic nutrition calculations, ingredient icons, and improved unit conversions, managing recipes and groceries is now easier and more accurate.

Alongside these features, this release includes a redesigned Pantry page and various fixes and improvements.

## Features

### Ingredient catalogue

Norish now ships with an ingredient catalogue based on the Open Food Facts ingredients taxonomy.

The catalogue drives several new features:

- **Ingredient management:** Browse, search, edit, merge, and organize ingredients under **Settings => Ingredients**. Ingredients can be grouped into parent-child relationships.
- **AI-assisted management:** Use **Fix catalogue** to have AI check flagged ingredients and tidy names.
- **New ingredients:** Server admins can have new ingredients cleaned and given an icon automatically under **Settings => Admin => AI & processing**.
- **Smarter pantry matching:** Ingredient relationships improve pantry matching. For example, having _red onion_ in your pantry also counts for recipes writing it in a different language.
- **Automatic nutrition calculations:** Recipes without nutrition information now automatically calculate calories, fat, carbohydrates, and protein per serving using nutritional datasets such as CIQUAL, USDA FoodData Central, and CoFID. No AI required anymore.
- **Nutrition corrections:** Adjust ingredient nutrition values and weights for your household, either manually or by selecting another nutritional data source.
- **Improved AI nutrition estimates:** AI now only estimates ingredients that couldn't be calculated automatically, rather than guessing nutrition for the entire recipe.
- **Ingredient icons:** Ingredients now have an icon, this is purely aestethic and can be turned off.
- **Unit conversions:** Convert ingredient quantities using catalogue data without relying on AI, AI-powered conversion remains available.
- **Permissions:** Server admins can control who may edit ingredients added by other users.

See [Ingredients](../groceries/ingredients.md), [Nutrition](../recipes/nutrition.md), and [Ingredient icons](../groceries/ingredient-icons.md).

### Redesigned Pantry page

The Pantry has moved from a panel to its own dedicated page.

Combined with the new ingredient catalogue and smarter ingredient matching, managing what you have at home and identifying what you need for recipes is now more streamlined.

See [Pantry](../groceries/pantry.md).

### Other improvements

- **Recipe planning:** Choose whether planning a recipe opens the groceries panel (default) or automatically adds ingredients to your grocery list. Configure this under **Settings => User => Preferences => After planning a recipe**.
- **User preferences:** Settings are now stored on the server rather than in the browser, with most preferences scoped per device type. Existing preferences will be reset after updating.
- **Measurement system:** Added the option to automatically select the measurement system under **Settings => User => Preferences**.
- **Cookbooks:** Cookbooks can now have their own cover images.
- **CalDAV:** Fixed meal times to correctly account for time zones instead of converting everything to UTC. Thanks to [@zombopanda](https://github.com/zombopanda).
- **Recipe imports:** Recipes imported from lecker.de now include their preparation steps. Thanks to [@skolodziej](https://github.com/skolodziej).
- **Language support:** Added Ukrainian translations.
- **Calendar** Minor redesign and correctly auto scrolls to todays date.
- **AI keys:** When an AI provider rejects a configured API key, server admins now see a warning on every page and under **Settings => Admin => AI & processing**, and flagged ingredients say the key was rejected. Before, a revoked key just made ingredient matching quietly worse.
- **Home screen icon:** Adding Norish to the home screen from Firefox on Android or from iOS Safari uses the Norish icon again instead of a default one ([#611](https://github.com/norish-recipes/norish/issues/611)).
- **Upload folder:** Norish now makes its uploads folder writable itself, so a host folder that Docker created as root no longer makes image uploads and imports fail ([#116](https://github.com/norish-recipes/norish/issues/116)). If your compose file sets `user: "1000:1000"`, remove that line to get this.

### Configuration

The following optional environment variables have been added:

- **`INGREDIENT_CATALOGUE_URL`:** Use a local mirror of the Open Food Facts ingredients taxonomy instead of the default source.
- **`INGREDIENT_REVIEW_CONCURRENCY`:** Control how many ingredients can be processed by AI simultaneously (default: `10`). Lower this value for self-hosted models that struggle with concurrent requests.

No additional configuration is required for the ingredient catalogue to work.

See [Server & runtime](../configuration/server-runtime.md#ingredient-catalogue).
