# v0.23.1-beta

## Summary

Follow-up to the grocery pricing that shipped in previous release. 
Mainly the grocery linking was configured too lose. Unlinking groceries
was not possible.

## Fixes and Improvements

- A grocery is linked to a shop product by itself only when the product's
  name **is** the grocery's name. Before, a grocery named "snoepjes" was
  quietly priced as a bag of "Fortuin salmiak snoepjes", because that was the
  one product carrying the word. A product whose name only contains the
  grocery's is now offered in the grocery panel, never taken.
- Typos such as "sneopjes" are still found as as "snoepjes". 
  One wrong, missing, extra or swapped letter is allowed on names of five 
  letters or more, two on names of nine or more. Shorter names
  have to match exactly, because one letter apart is a different word there.
- A grocery can be unlinked from its product. Open it and press **Unlink
  product**: the row loses its price, and the Store treats the name as one it
  has no product for until you pick or type one.
