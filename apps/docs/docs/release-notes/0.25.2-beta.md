# v0.25.2-beta

## Summary

Improves ingredient parsing and Recipe Keeper import.

## Fixes and Improvements

- **Ingredient parsing:** Improved handling of ingredient amounts, quantities, and names to ensure ingredients are parsed correctly and scale with servings.
- **Ingredient matching:** Improved recognition of ingredients written with different language conventions, reducing duplicate ingredients.
- **Recipe Keeper imports:** Fixed issues with imported recipe steps and ingredient amounts.
