# v0.26.1-beta

## Summary

This release adds selecting several recipes at once, clearing the grocery list, abbreviated units and editing recipes through the API. It also fixes imports, CalDAV setup with private certificates and Recipe Archive exports.

## Features

- Show units abbreviated, like `500 g` and `2 tbsp`, under **Settings => User => Preferences => Units**. Units without a short form, like cups, still read as words. See the [recipe page documentation](/recipes/recipe-page#units) ([#694](https://github.com/norish-recipes/norish/issues/694)).
- Select several recipes in the Library or on a cookbook page by pressing and holding a card, then delete them or add them to a cookbook in one go. See [Selecting recipes](/recipes/selecting).
- The planned recipes API returns planned notes as well when you add `?include=notes`. Each item now carries `itemType` and `title`. See the [API reference](/reference/api) ([#696](https://github.com/norish-recipes/norish/issues/696)).
- Edit a recipe through the API with `PATCH /recipes/{id}`: send only the fields to change and the recipe's `version`. See the [API reference](/reference/api) ([#698](https://github.com/norish-recipes/norish/issues/698)).
- Clear the whole grocery list, one store or one recipe's items in one go, each after a confirmation. See [Clearing the list](/groceries/clearing) ([#558](https://github.com/norish-recipes/norish/issues/558)).

## Fixes and Improvements

- URL imports keep ingredient section headings with **Always use AI importing** on, or `forceAI` on the import API ([#685](https://github.com/norish-recipes/norish/issues/685)).
- AI imports open in the measurement system the source is written in, instead of always in metric ([#693](https://github.com/norish-recipes/norish/issues/693)).
- Video transcription works with OpenAI-compatible servers that read only WAV, such as mlx-serve: a refused MP3 is sent again as WAV ([#690](https://github.com/norish-recipes/norish/issues/690)).
- Recipe cards in the Library and planned recipes under Today are real links, so a middle click or Ctrl/Cmd-click opens them in a new tab ([#555](https://github.com/norish-recipes/norish/issues/555)).
- CalDAV setup lets you press **Test** as soon as the server, username and password are filled in, and a failed test says why, such as an untrusted certificate. A server with a certificate from your own certificate authority, or a self-signed one, can be trusted from the test, see [Private certificates](/configuration/server-runtime#private-certificates) ([#703](https://github.com/norish-recipes/norish/issues/703)).
- Exporting a Recipe Archive from settings no longer fails now and then with "Export failed" after 30 seconds.
- An import that ends just as the Library opens no longer leaves its loading card behind, and an import still running no longer shows under **Cookbooks**.
- Timers are found in Arabic steps that use Arabic punctuation, and the timer keywords in admin settings accept the Arabic comma ([#707](https://github.com/norish-recipes/norish/pull/707)).
- Deleting a recipe that someone else changed in the meantime no longer removes its images while the recipe stays.
- After a dropped connection, the app catches up on updates of a kind that had not happened yet when it connected.
- The confirmations for share links and for deleting a cuisine no longer open underneath the navbar.
- When the embedded parser exits during startup, the server log includes its last lines of output.

## Upgrade notes

- `NODE_EXTRA_CA_CERTS` is a new optional environment variable. Point it at your certificate authority's file to trust CalDAV and AI servers it signed. See [Private certificates](/configuration/server-runtime#private-certificates).
