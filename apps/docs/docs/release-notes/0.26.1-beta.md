# v0.26.1-beta

## Summary

## Features

- Show units abbreviated, like `500 g` and `2 tbsp`, under **Settings => User => Preferences => Units**. Units without a short form, like cups, still read as words. See the [recipe page documentation](/recipes/recipe-page#units) ([#694](https://github.com/norish-recipes/norish/issues/694)).
- The planned recipes API returns planned notes as well when you add `?include=notes`. Each item now carries `itemType` and `title`. See the [API reference](/reference/api) ([#696](https://github.com/norish-recipes/norish/issues/696)).

## Fixes and Improvements

- URL imports keep ingredient section headings with **Always use AI importing** on, or `forceAI` on the import API ([#685](https://github.com/norish-recipes/norish/issues/685)).
- AI imports open in the measurement system the source is written in, instead of always in metric ([#693](https://github.com/norish-recipes/norish/issues/693)).
- Video transcription works with OpenAI-compatible servers that read only WAV, such as mlx-serve: a refused MP3 is sent again as WAV ([#690](https://github.com/norish-recipes/norish/issues/690)).
- Recipe cards in the Library and planned recipes under Today are real links, so a middle click or Ctrl/Cmd-click opens them in a new tab ([#555](https://github.com/norish-recipes/norish/issues/555)).
