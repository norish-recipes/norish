# v0.28.0-beta

## Summary

## Features

### Settings in the iPhone app

Open **All settings** from your avatar to manage your profile, preferences,
allergies, household and connections. You can also change server, open support,
see version information and sign out.

## Fixes and Improvements

- On iPhone, you can copy an active recipe share link made in 0.28 or later from Settings.
- On the web, Norish tells you when a profile save is refused because the profile changed elsewhere.
- On the web, failed household and recipe share-link actions show a message.
- On the web, the API key name field stops at 32 characters and the household name field at 100.
- The web app reconnects faster after the browser comes back online.
- New API keys and recipe share links are no longer stored for replay after creation.
