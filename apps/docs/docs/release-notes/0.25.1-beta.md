# v0.25.1-beta

:::warning
**Docker Compose configuration change:** When upgrading to `norishapp/obscura:0.2.4-norish.1`, 
you must configure `OBSCURA_CDP_TOKEN` for both the `norish` and `obscura` services. See the [upgrade notes](#upgrade-notes) for instructions.
:::

## Summary

This release makes recipe imports better. It corrects some calendar and settings problems, and it makes the app icons and favicons the same across Norish.

## Features

- **MCP server:** External AI agents can connect to Norish at `/api/mcp` with an API key for that user. Each agent gets exactly the recipes, groceries, and meal-plan access of that user. See [MCP server](/reference/mcp).

## Fixes and Improvements

- **Recipe Keeper import:** Import recipe archives via **Settings => Import recipe archive**. Files must have the `RecipeKeeper_….zip` name.
- **Linked step ingredients:** Mealie and Tandoor imports now preserve ingredients that are part of recipe steps.
- **Favourites:** Mela and Mealie imports now include favourite recipes.
- **Mealie imports:** Cuisine, tools, notes, and cooking times are now imported.
- **Data export:** Norish exports now include cookbooks.
- **Duplicate recipe names:** You can now import two recipes with the same name, if their URLs are different.
- **Recipe enrichment:** Automatic recipe enrichment now also runs on imported recipe archives when enabled.
- **Settings:** A setting change now stays as you set it.
- **Profile images:** Transparent profile images now do not show a color during start.
- **Calendar:** The calendar now opens on the present date instead of a date before.
- **Store order:** Stores now keep the same order in the Store view. When you move a Store past many others, it does not go back.
- **Icons and favicons:** App icons and favicons are now the same across the Norish app, start view, and documentation.

## Upgrade notes

- **The Obscura app is now `norishapp/obscura:0.2.4-norish.1`.** It is upstream [Obscura 0.2.4](https://github.com/h4ckf0r0day/obscura/releases/tag/v0.2.4), which corrects errors when a view ends. It also starts a failed process again. The tag does not change, so `docker compose pull` does not get it.
- **OBSCURA_CDP_TOKEN** Obscura 0.2.4 does not start without a `OBSCURA_CDP_TOKEN` token. Generate it with `openssl rand -hex 32`.

  ```yaml
  services:
    norish:
      environment:
        OBSCURA_CDP_TOKEN: <your-token>
    obscura:
      image: norishapp/obscura:0.2.4-norish.1
      environment:
        OBSCURA_CDP_TOKEN: <your-token>
  ```

  Then run `docker compose pull` and `docker compose up -d`. See [Recipe parser](/configuration/parser#settings).

- **Obscura has a `latest` tag.** Use `norishapp/obscura:latest` to follow new Obscura builds without a change to your compose file.
