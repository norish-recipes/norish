# v0.25.1-beta

:::warning
**Docker Compose configuration change:** When upgrading to `norishapp/obscura:0.2.4-norish.1`,
you must configure `OBSCURA_CDP_TOKEN` for both the `norish` and `obscura` services. See the [upgrade notes](#upgrade-notes) for instructions.
:::

## Summary

This release improves recipe imports, fixes several calendar and settings issues and aligns app icons and favicons across Norish.

## Features

### Choose the recipe thumbnail

The first image in a recipe gallery is the recipe thumbnail. Select the
thumbnail control on a different image to put it at the front. The recipe view
has the new thumbnail. See [the recipe form](../recipes/creating-and-editing.md#choosing-the-thumbnail).

### The gallery keeps your images

**Generate Picture** makes its image the first image in the recipe. The gallery
keeps the images that are not from AI. AI does not remove them or their files.
See [the image controls](../recipes/enrichment.md#running-one-yourself).

## Fixes and Improvements

- **Recipe Keeper import:** Import recipe archives via **Settings => Import recipe archive**. Files must use the `RecipeKeeper_….zip` naming format.
- **Linked step ingredients:** Mealie and Tandoor imports now preserve ingredients linked to recipe steps.
- **Favourites:** Mela and Mealie imports now include favourite recipes.
- **Mealie imports:** Cuisine, tools, notes, and cooking times are now imported.
- **Data export:** Norish exports now include cookbooks.
- **Duplicate recipe names:** Recipes with the same name can now both be imported, provided their URLs are different.
- **Recipe enrichment:** Automatic recipe enrichment now also runs on imported recipe archives when enabled.
- **Settings:** Changing a setting while a previous change is still saving no longer causes the value to briefly revert.
- **Profile pictures:** Transparent profile pictures no longer flash green during startup.
- **Calendar:** The calendar now opens on today instead of a date several weeks in the past.
- **Store ordering:** Stores now maintain a consistent order in the Store manager. Dragging a Store past multiple others no longer causes it to snap back.
- **Icons and favicons:** App icons and favicons are now consistent across the Norish app, landing page, and documentation.

## Upgrade notes

- **The Obscura browser moves to `norishapp/obscura:0.2.4-norish.1`** It is upstream [Obscura 0.2.4](https://github.com/h4ckf0r0day/obscura/releases/tag/v0.2.4), which fixes crashes when a page closes and restarts a failed worker. The tag is pinned, so `docker compose pull` does not pick it up.
- **OBSCURA_CDP_TOKEN** Obscura 0.2.4 won't start without a `OBSCURA_CDP_TOKEN` token. Generate it with `openssl rand -hex 32`.

  ```yaml
  services:
    norish:
      environment:
        OBSCURA_CDP_TOKEN: <your-token>
    obscura:
      image: norishapp/obscura:0.2.4-norish.1
      environment:
        OBSCURA_CDP_TOKEN: <your-token>
  ```

  Then run `docker compose pull` and `docker compose up -d`. See [Recipe parser](/configuration/parser#settings).

- **Obscura has a `latest` tag.** Use `norishapp/obscura:latest` to follow new Obscura builds without editing your compose file.
