# v0.21.0-beta

## Summary

This release updates the UI, a redesign for the menu, themeing is updated a bit. Landing page is redone to look less SaaS.

## Features

### Theme update

- **Chips** A chip is are made more coherent, no more glass chips either they are accent colored when active or a soft color when not.
- **Glass look** Initially I wanted to go for a liquid glass look, recently I began annoying myself by it, it didn't look good and it was trying to be something it is not.
- **Mobile menu** The mobile menu no longer hides, that resulted in some annoying behaviour, it is now always visible but scales down when scrolling down.
- **Sign-in page** Improved the error messaging a bit, and follow the themeing.

### Hidden Items

- Controls to hide UI elements are now all grouped under one multi-select in the user settings.
- Hidden Items is a per-device choice, like the other view settings: hide nutrition on your phone and keep it on your desktop.
- The server decides what to render - so the client won't see flickering anymore.
- When turning off recipe provenance the origin flags do remain besides the title, thats intentional.

[Hidden Items](../recipes/hidden-items.md).

## Fixes and Improvements

- **Profile pictures stay fresh.** Replacing your profile picture now shows up
  everywhere right away, also in the installed app, and other people in your
  household see it within seconds without reloading. Before, an installed app
  could keep showing your old picture forever.
- **Profile pictures are always a circle** at every size, and while a picture
  loads (or when you are offline) you see your initials on a colored disc
  instead of an empty box.
- **A proper iOS app icon.** The home-screen icon is now a flat green tile with
  the cream Norish mark, so iOS 26's Liquid Glass treatment gets something it
  can work with instead of compositing our old transparent circle onto black.
- **Splash screens on every device.** The iOS startup image list now covers all
  current iPhones and iPads plus the older SE and Plus shapes, so the splash no
  longer appears only on some devices.
- **New sign-in tagline.** The login page now reads "Any source, any recipe."
  in all 14 languages, replacing the old line (and its broken French
  translation).

## Obscura

- **URL imports render in [Obscura](https://github.com/h4ckf0r0day/obscura) instead of a third-party Chromium container.**
  The `chrome-headless` service is replaced by `obscura`. See [Recipe parser](../configuration/parser.md), and the Upgrade notes
  below as this is a **breaking** change.

## Upgrade notes

- **Remove and re-add the app to your iOS home screen** to pick up the new app
  icon and the splash screen fixes. iOS freezes both at the moment you add the
  app, so an existing installation keeps the old look until you re-add it.

- **The individual display switches were replaced by Hidden Items.** The
  separate settings switches for ratings, favorites, ingredient conversion
  and recipe timers are gone; the new Hidden Items control covers all of them
  and more. There is deliberately no migration: everything starts visible, so
  if you had ratings, favorites or timers hidden you will need to hide them
  once more in the new control.

- **Breaking: `CHROME_WS_ENDPOINT` is replaced by `OBSCURA_ENDPOINT`, and the
  `chrome-headless` service by `obscura`.** There is no alias and no deprecation
  period — an unchanged compose file leaves URL imports pointing at a browser
  that is no longer there. In your compose file, replace the `chrome-headless`
  service with:

  ```yaml
  obscura:
    image: norishapp/obscura:0.2.0-norish.1
    restart: unless-stopped
  ```

  then swap `CHROME_WS_ENDPOINT: ws://chrome-headless:3000` for
  `OBSCURA_ENDPOINT: ws://obscura:9222` in the `norish` service and update any
  `depends_on` entry. The image needs no command, no flags, and no shared-memory
  tuning; it does not publish a port, and it should not — anything that can
  reach it can drive the browser. If you run the browser on another host, point
  `OBSCURA_ENDPOINT` at that Obscura CDP server instead.
