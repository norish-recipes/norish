# Manage household content

Open **Settings**, then **Content** on web or mobile. Choose **Tags**, **Cuisines**, **Categories** or **Ingredients**. Tags and Categories organize recipes, Cuisines describe their provenance, and Ingredients make up the food catalogue.

Each household has its own entries. The list also includes server Cuisines marked **From your server**, built-in Categories marked **Built in**, and the shared ingredient seed. Members can change their household's entries. Server admins can change server Cuisines and seeded ingredients; built-in Categories cannot be changed. Anyone can add a household spelling to a seeded ingredient.

Search or filter the list, then use **Add** to create an entry. Open an entry to rename or delete it and see **Used by**, which lists your household's recipes. For an ingredient, **Used by** shows a count and pages of recipes. On mobile, long-press an editable Tag, Cuisine or Category for **Rename**, **Show recipes** and **Delete**. Renaming a list entry to an existing name merges them. Deleting a Tag, Cuisine or Category removes it from the recipes that use it. The confirmation shows the count. When a server admin adds or renames a server Cuisine to a name a household already has, the household's recipes use the server entry. When a server admin deletes a server Cuisine, the count includes recipes from every household on the server.

For ingredient spellings, nutrition and icons, see [Manage ingredients](/groceries/ingredients). Deleting an ingredient keeps the original text in recipes and groceries and removes matching Pantry entries.

On mobile, the **Ingredients** tab lists data sources and has a row to export the catalogue.
