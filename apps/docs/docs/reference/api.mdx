# API reference

In account settings, open **API keys** and create a key. Send it in an `x-api-key` header or as `Authorization: Bearer <key>`. Use your own server address in the examples.

Each key allows [500 requests per hour by default](/configuration/server-runtime#auth-rate-limiting). A `429 Too Many Requests` response gives the wait in seconds in `Retry-After`.

To import a URL, send it to `POST /api/v1/recipes/import/url` and poll the
returned `statusUrl`. Add `?wait=30` to a status request to wait for up to
30 seconds. The limit is 60 seconds.

`GET /api/v1/recipes/{id}/nutrition` returns values per serving and a source
of `supplied`, `worked-out`, or `none`. Extras are in `perServing.extras`,
and `extrasCoverage` reports what share of the counted ingredient weight
each extra covers.
