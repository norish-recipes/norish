# Change how Norish looks

## Floating bar style

On a phone, the web app's bottom navigation and the other floating bars
stand on the opposite theme's colours: a dark bar in the light theme and a
light bar in the dark theme, so they stand out from the page under them.

To draw them in your theme's own colours instead, open **Settings**, then
**Account**, and under **Preferences** set **Floating bar style** to
**Matches theme**. **Contrasting** brings back the default.

![The bottom navigation in the dark theme, set to Matches theme](/img/screenshots/floating-bar-style-match.png)

Like the other preferences there, the choice is kept per device type, so a
phone and a desktop can differ.
