# Scripts

**`measure-page-loads.ts`** times full page loads on a throttled phone. Build with `pnpm build`, start the production server (`PORT=3400 AUTH_URL=http://localhost:3400 AUTH_RATE_LIMIT_ENABLED=false UPLOADS_DIR=… pnpm --filter @norish/web run start`), then run `pnpm --filter @norish/web run measure:page-loads --email … --password …` with an account that has recipes (the newest one rated and a favourite), a cookbook, a planned meal today, priced groceries filed under an aisle, and Pantry suggestions. Each load is a fresh Pixel 7 with the CPU slowed 4×, behind a proxy that shares one 1.6 Mbps down / 750 kbps up link. For every page it prints the median and spread of 15 loads (`--runs`) for first paint, for the first frame each piece of content is drawn in, the document's gzip size and the JavaScript the load downloads (encoded, added up from its script responses), then the time from a tap on a recipe card to that recipe. Add `--sw allow` to install the service worker before each load (`--sw fetch` also turns its navigation preload off), `--share /share/<token>` to include a shared recipe, and `--only /,recipe,tap` to measure some pages.

**`measure-renders.ts`** counts React's mounts and re-renders per scripted action, on the dev server (`pnpm dev`, whose build keeps component names): `pnpm --filter @norish/web run measure:renders groceries --base … --email … --password …`. Give it an account of its own: every run replaces that account's groceries with the script's data set through the API, and it refuses a list holding anything else. Per action it prints each component's mounts and updates, sorted by count, with what changed behind each update: a prop's name, `(state)`, `(context)`, or `(parent)` when only the parent rendered. The `groceries` scenario checks an item, adds one, opens the edit panel, takes the echo of a second signed-in phone checking an item, and switches the view mode. tRPC responses and socket messages reach the page one at a time after fixed delays, so unchanged code prints the same counts.
