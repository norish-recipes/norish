# Scripts

**`measure-page-loads.ts`** times full page loads on a throttled phone. Build with `pnpm build`, start the production server (`PORT=3400 AUTH_URL=http://localhost:3400 AUTH_RATE_LIMIT_ENABLED=false UPLOADS_DIR=… pnpm --filter @norish/web run start`), then run `pnpm --filter @norish/web run measure:page-loads --email … --password …` with an account that has recipes (the newest one rated and a favourite), a cookbook, a planned meal today, priced groceries filed under an aisle, and Pantry suggestions. Each load is a fresh Pixel 7 with the CPU slowed 4×, behind a proxy that shares one 1.6 Mbps down / 750 kbps up link. For every page it prints the median and spread of 15 loads (`--runs`) for first paint, for the first frame each piece of content is drawn in, and the document's gzip size, then the time from a tap on a recipe card to that recipe. Add `--sw allow` to install the service worker before each load (`--sw fetch` also turns its navigation preload off), `--share /share/<token>` to include a shared recipe, and `--only /,recipe,tap` to measure some pages.
